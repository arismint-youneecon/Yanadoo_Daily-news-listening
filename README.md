# 아침 영어 뉴스 클럽

영어회화 동아리 회원이 매일 아침 2분 영어 뉴스 브리핑을 듣고 공부하는 웹 앱입니다.
Claude 계정 없이 개인 접속 코드로 들어오며, 관리자는 회원별 접속일과 학습 현황을 볼 수 있습니다.

## 구조

| 부분 | 하는 일 | 위치 |
|---|---|---|
| 웹 앱 | 로그인, 오늘의 브리핑 3개, 지난 브리핑, 내 기록, 회원 관리 | `index.html`, `app.js`, `config.js` (GitHub Pages) |
| 콘텐츠 | 날짜별 브리핑(대본, 해석, 단어, 음성) | `data/<날짜>.json`, `data/index.json`, `audio/*.mp3` |
| 회원 기록 | 접속 코드, 접속일, 재생·완청·단어 조회 기록 | Supabase (`supabase/setup.sql`) |
| 매일 갱신 | 아침마다 Claude 예약 작업이 브리핑 3개를 만들어 이 저장소에 올림 | `scripts/add_briefing.py` |

## 처음 설정

1. Supabase 프로젝트의 SQL Editor에 `supabase/setup.sql` 전체를 붙여넣습니다. 마지막 줄의 `'관리자 이름'`을 본인 이름으로 바꾸고 실행하면 관리자 접속 코드가 나옵니다.
2. `config.js`에 Supabase Project URL과 anon key를 넣습니다. anon key는 공개용 키입니다. service_role key는 절대 넣지 마세요.
3. GitHub 저장소 Settings → Pages에서 Source를 `main` 브랜치의 `/ (root)`로 지정합니다.
4. 사이트에 관리자 코드로 들어가 `관리` 탭에서 회원을 추가하고, 화면에 나온 코드를 회원에게 전달합니다.

`config.js`의 주소를 비워 두면 서버 없이 이 브라우저에만 기록하는 데모 모드로 동작합니다(데모 관리자 코드 `DEMO2026`).

## 보안과 개인정보

- 무료 GitHub Pages는 공개 저장소에서 운영되므로, 브리핑 파일(MP3, 대본)은 주소를 아는 사람이면 열 수 있습니다. 접속 코드가 지키는 것은 앱 화면과 회원 기록입니다.
- 회원 기록 테이블은 직접 읽거나 쓸 수 없고, 접속 코드를 확인하는 함수로만 다룹니다. 코드는 해시로만 저장됩니다.
- 10분 동안 틀린 코드가 50번을 넘으면 잠시 로그인이 막힙니다.
- 접속일과 학습 기록을 남기므로 회원에게 미리 알리고 동의를 받아 주세요.

## 음성 파일 보관

브리핑 1개의 MP3는 약 0.7MB(48kbps)입니다. 60일이 지난 음성 파일은 자동으로 지워지고, 대본과 해석은 그대로 남습니다.
